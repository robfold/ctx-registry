사내 문서를 읽는 코딩 에이전트를 쓰는 팀에게

사내 문서가 내 Cloudflare 밖으로 나가지 않습니다.

ctx-registry는 오픈소스 context CLI용 자체 호스팅 레지스트리입니다. 문서 패키지를 한 번 만들면, 모든 맥과 에이전트가 내 Cloudflare 계정에서 같은 파일을 받습니다. 내가 갖고 있지 않은 패키지는 공개 레지스트리에서 받아 오니 다른 것은 바뀌지 않습니다.

지금 코딩 에이전트가 가장 많이 쓰는 문서 서비스 Context7의 공개 이슈 게시판에서 옮겼습니다. 원문은 영어입니다.

Context7은 자체 호스팅을 Enterprise 플랜에서 제공합니다. ctx-registry는 이미 가진 Cloudflare 계정에 무료로 띄우는 자체 호스팅 레지스트리입니다.

동작 방식

에이전트는 지금처럼 context CLI와 MCP 서버를 씁니다. 바뀌는 것은 파일을 받아 오는 서버 하나입니다.

  1. 패키지 만들기

    저장소, 문서 사이트, 폴더를 내 맥에서 SQLite 파일 하나로 만듭니다.

    context add https://github.com/honojs/hono

  2. 올리기

    파일 하나만, 또는 만든 것 전부를 올립니다. 서버에 이미 있는 패키지는 건너뜁니다.

    node bin/ctx-publish.mjs --all

  3. 어디서나 설치

    어느 맥, 어느 에이전트든 CLI나 MCP 도구로 받습니다.

    context install npm/next 16.4.6

  4. 오프라인 검색

    검색은 에이전트가 도는 맥에서 합니다. 네트워크도, 호출 요금도 없습니다.

    context query next@16.4.6 "middleware"

에이전트에게 달라지는 것

검색은 에이전트가 도는 곳에서 합니다
  • 에이전트가 몇 번을 찾아봐도 검색 요금이 없습니다.
  • 설치한 문서는 오프라인에서도, 서버가 멈춰도 됩니다.
비공개 패키지는 내 R2 버킷에 있습니다
  • 사내 API 문서가 내가 관리하는 계정 안에 남습니다.
  • 패키지는 내가 올릴 때 바뀝니다. 남의 수집기가 돌 때가 아닙니다.
서버 하나로 전부 받습니다
  • 내가 없는 패키지는 공개 레지스트리에서 그대로 받아 옵니다.
  • 전환은 ~/.context/config.json의 한 항목이고, 되돌리기도 한 항목입니다.
여러 버전을 나란히 둡니다
  • next@16.2.9와 next@16.4.6을 둘 다 설치할 수 있습니다.
  • 에이전트가 내가 실제로 쓰는 버전의 문서를 읽습니다.

Context7 수치는 2026년 11월 21일에 context7.com/plans에서 읽었습니다. Context7은 공개 라이브러리 수천 개를 대신 파싱해 둡니다. ctx-registry는 그 부분을 Neuledge 공개 레지스트리에 맡깁니다.

ctx-registry 비용: 설치 1회는 R2 목록 조회 최대 2번과 읽기 최대 2번입니다. R2는 내보내기 요금이 없고, 저장 10GB까지 무료입니다.

우리 에이전트가 직접 씁니다

  • 196개 패키지 제공 중
  • 361.6 MBR2 버킷 하나, 무료 한도 안
  • 16개 시험, 방어 코드를 일부러 깨서 시험이 실패하는지 확인

여기서 설치한 패키지는 원본 파일과 바이트 단위로 같았습니다. 서버에 없던 패키지는 공개 레지스트리에서 받아 왔습니다.

클론한 뒤 명령 다섯 줄로 배포

Cloudflare 계정과 Node 22.13 이상이 필요합니다.

Worker 배포

git clone https://github.com/robfold/ctx-registry
cd ctx-registry
npm install
npx wrangler r2 bucket create ctx-registry
npm run cf:deploy
openssl rand -hex 32 | npx wrangler secret put READ_TOKEN
openssl rand -hex 32 | npx wrangler secret put PUBLISH_TOKEN

두 토큰을 넣기 전에는 /healthz 말고 모든 경로가 404입니다. 두 토큰은 비밀번호 관리자에 보관합니다.

CLI 연결

{
  "servers": [
    { "name": "mine", "default": true,
      "url": "https://ctx-registry.<you>.workers.dev/t/<READ_TOKEN>" },
    { "name": "neuledge", "url": "https://api.context.neuledge.com" }
  ]
}

맥마다 ~/.context/config.json으로 저장합니다. 되돌리려면 mine 항목을 지웁니다. 그러면 CLI가 공개 레지스트리로 돌아갑니다.

아직 못 하는 것

  • 읽기 토큰이 URL에 들어갑니다. API 키처럼 다루고, 새면 명령 한 줄로 바꿉니다.
  • 읽기 토큰을 가진 쪽에는 사용량 제한이 없습니다.
  • 패키지 하나는 95MB보다 작아야 합니다.
  • 패키지는 내 맥에서 만듭니다. 자동 재빌드는 이번 판에 없습니다.

에이전트에게 내 소유의 서재를 주세요.
