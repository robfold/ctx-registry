Context7의 대안

Context7, 엣지에서. 빠르고, 거의 공짜, 한도 없이.

에이전트에 주소 한 줄만 붙이면 됩니다. Context7과 같은 도구 두 개로 라이브러리 공식 문서에서 맞는 절을 찾아 줍니다. 서버가 Cloudflare 엣지에서 돌아서 질문 하나의 원가가 거의 0입니다. 그래서 한도 없이, 거의 공짜로 드릴 수 있습니다.

설치할 것이 없습니다. 받은 주소를 에이전트에 붙이면 끝입니다. 그다음은 Context7을 쓸 때와 같습니다. 에이전트가 resolve-library-id로 라이브러리를 찾고, query-docs로 묻습니다.

왜 거의 공짜인가

Context7은 질문을 셉니다. 무료는 월 1,000번에서 막히고, 유료는 좌석당 월 10달러에 1,000번마다 5달러를 더 받습니다. 우리 서버는 Cloudflare 엣지에서 돌아서 질문 100만 개의 원가가 약 11달러입니다. 그래서 질문을 셀 필요가 없습니다.

Context7 수치는 2026년 11월 21일에 context7.com/plans에서 읽었습니다. 우리 원가는 Cloudflare 정가로 계산한 추정입니다. 정식 가격은 아직 정하지 않았습니다.

지금 돌아가는 것

  • 197개 라이브러리 공식 문서
  • 117,956개 절, 단어와 의미로 검색
  • 0.16–0.30초시험 질문 6개의 서버 시간 중앙값

"run a job every hour with cron triggers"(cron으로 1시간마다 작업 돌리기)를 물으면 Cloudflare의 Cron Triggers 문서를 먼저 돌려줍니다. Context7식 ID /vercel/next.js로 fetch를 1분마다 새로 고치는 법을 물으면 Next.js 재검증 문서를 돌려줍니다. 시험 질문은 모두 영어로 했습니다.

아직 못 하는 것

  • 라이브러리는 197개입니다. Context7은 수천 개를 갖고 있습니다. 아래 칸에 쓰는 라이브러리를 적어 주시면 먼저 넣습니다.
  • "protect a dashboard route"(대시보드 경로 보호)처럼 할 일로 묻는 질문에는 아직 Context7의 상위 답이 더 정확합니다. Context7은 코드 예시마다 제목과 요약을 따로 써 둡니다.
  • 베타입니다. 주소는 이메일로 한 분씩 보내 드립니다.
