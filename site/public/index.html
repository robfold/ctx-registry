An alternative to Context7

Context7, on the edge. Fast, nearly free, no quota.

Add one URL to your coding agent. With the same two tools as Context7, it finds the right sections of a library's official docs. Our server runs on Cloudflare's edge, so each question costs almost nothing to answer. That is why there is no quota and almost no price.

Connecting takes one line

There is nothing to install. Add the URL you get to your agent and you are done. After that it works the way Context7 does: the agent finds the library with resolve-library-id, then asks with query-docs.

Claude Code

claude mcp add --transport http docs <your URL>

Other MCP clients

{ "mcpServers": { "docs": { "url": "<your URL>" } } }

Why it is nearly free

Context7 counts your questions. Free stops at 1,000 a month; Pro is $10 per seat a month plus $5 for every extra 1,000. Our server runs on Cloudflare's edge, where a million questions cost about $11 to answer. So there is no reason to count them.

What runs today

  • 197libraries of official docs
  • 117,956sections searchable by keyword and meaning
  • 0.16–0.30 smedian server time on six test questions

Asked "run a job every hour with cron triggers", it returns Cloudflare's Cron Triggers docs first. Asked "refresh a fetch every minute" with the Context7-style ID /vercel/next.js, it returns the Next.js revalidation docs.

What it doesn't do yet

  • It holds 197 libraries; Context7 holds thousands. Tell us the libraries you use in the form below and we add them first.
  • On questions phrased as a task, such as "protect a dashboard route", Context7's top answers are still sharper. It writes its own title and summary for each code example.
  • It is a beta. URLs go out by email, one person at a time.
